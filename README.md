# InfoFlow

정보 주체·처리·시스템·저장소와 정보 이동 방향을 기록하는 한국어 로컬 흐름도 편집기입니다. React, TypeScript, Vite로 구현하며 서버 동기화는 제공하지 않습니다.

## 실행

Node.js 20.19+ 또는 22.12+에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저로 여세요. `npm run test`, `npm run lint`, `npm run build`를 실행하면 검증 및 `dist/` 정적 배포 산출물을 만들 수 있습니다. `npm run preview`로 빌드 결과를 확인합니다. `file://`로 HTML을 직접 열지 않습니다.

## 배포와 사용

- 서비스 주소: https://rebugui.github.io/infoflow/
- `main`에 푸시하면 GitHub Actions가 검사 및 빌드한 뒤 GitHub Pages에 배포합니다.
- 기본 합성 예제 또는 빈 도면에서 시작합니다. 실제 운영 설정이나 개인정보 값 대신 항목명·합성 데이터를 사용하세요. 도면과 검토 경고가 인증이나 법적 적합성을 보장하지는 않습니다.
- 왼쪽 목록·추가에서 노드를 만들고 연결점 드래그 또는 흐름 폼으로 정보 이동 방향을 기록합니다. 오른쪽 속성에서 값을 편집하고 적용합니다. 문서 정보, 변경이력, 다중 장, 이름 변경과 복제를 지원합니다.
- 노드 드래그와 방향키 이동은 좌표를 프로젝트에 확정하며 한 동작씩 실행 취소·다시 실행할 수 있습니다. 자동 배치는 직접 지정한 위치를 변경하므로 확인 후 적용합니다.
- 화면 폭 900px 이하에서는 **도면 / 목록·추가 / 속성·검토**를 전환합니다. 메뉴에서 문서 정보·자동 배치·불러오기·새 프로젝트·출력에 접근합니다. 모바일 전용 새 편집 도구는 없으며 기존 캔버스 조작을 사용합니다.

`examples/information-flow-demo.json`은 실제 값이 아닌 합성 예제입니다. 기존 프로젝트를 바꾸기 전 JSON 백업을 저장하세요.

## 저장 및 백업

- `infoflow-project-v1` 키의 브라우저 localStorage에 자동 저장합니다. HTTPS 또는 localhost의 Web Locks 지원 브라우저에서 수정 버전 탭끼리만 배타적으로 쓰며, 구버전 앱 탭과 동시에 편집하지 마세요.
- 다른 탭이 데이터를 변경하면 이 탭의 자동 저장을 멈춥니다. **현재 편집 JSON 백업**으로 메모리의 작업을 보관한 뒤 확인하고 **최신 내용 다시 불러오기**를 사용하세요. 저장 중 또는 저장 실패·미지원 상태에서는 저장 완료로 간주하지 말고 JSON을 백업하세요.
- 손상된 저장 원본은 자동으로 덮어쓰지 않습니다. 복구 화면에서 원문을 먼저 내려받은 뒤 확인하고 새 프로젝트로 시작할 수 있습니다. 저장 접근 거부 또는 Web Locks 미지원에서도 메모리 편집과 JSON 백업은 가능합니다.
- 브라우저 프로필·주소마다 저장 영역이 다릅니다. 사이트 데이터를 지우면 로컬 원본이 없어집니다. JSON에는 전체 프로젝트가 평문으로 들어 있고 localStorage도 암호화되지 않으므로 안전하게 보관하세요. 앱별 키 분리는 접근통제가 아닙니다.
- 최근 100개 편집 작업의 undo/redo는 현재 세션에만 있으며 새로고침하면 이력이 초기화됩니다.

## 출력

- **PPTX 현재 장/전체 장**: 편집 가능한 선·도형·라벨, 타이틀·범례와 전체 속성·변경이력 표.
- **PNG**: 현재 장의 흰 배경 도면을 2배 픽셀 해상도로 저장.
- **SVG**: 현재 장 도면. HTML 라벨의 `foreignObject`를 지원하는 뷰어가 필요합니다.
- **PDF**: 전체 장, A3 가로, 장마다 한 페이지의 이미지 기반 도면.
- **JSON**: 모든 값과 ID, 장·좌표·변경이력을 보존하는 편집 가능한 평문 원본.

PNG·SVG·PDF는 도면 이미지이며 JSON·PPTX와 달리 속성표를 포함하지 않습니다. 폰트와 렌더링은 운영체제/뷰어에 따라 다를 수 있습니다.
